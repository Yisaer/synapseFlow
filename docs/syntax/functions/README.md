# SQL Functions

This directory contains function-system design notes for StreamDialect.

- `aggregate_rewrite.md`: Parser-side aggregate placeholder rewrite and planner contract.
- `date_time_functions.md`: Timestamp-based date and time scalar function semantics.
- `function_semantics.md`: Function taxonomy, metadata model, registry ownership, and testing
  dimensions.
- `merge_agg.md`: Shallow object aggregation and duplicate-field overwrite semantics.
- `schema_version.md`: Planner-bound named schema revision function semantics.
