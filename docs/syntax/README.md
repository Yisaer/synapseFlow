# Syntax Docs

This section contains SQL-visible language semantics for StreamDialect and configuration expression
syntax used by runtime APIs.

- `datatypes/`: Schema data types, JSON decode behavior, and type-specific design notes.
- `functions/`: Function taxonomy, aggregate rewrite behavior, and function-system constraints.
- `language/`: Expression and SELECT-level semantics.
- `windows/`: Window syntax and window-specific execution semantics.
- `connectors/`: Connector configuration string templates.
- `pipeline_schedule_cron.md`: Linux-compatible pipeline schedule cron syntax and UTC semantics.
